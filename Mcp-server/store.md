# Search Functionality

This section describes the search functionality of the online store.

## How to Search

*   Users can search for products using the search bar at the top of the page.
*   Search results can be filtered by category, price, and other attributes.

## Search API

*   **Endpoint:** `/api/search`
*   **Method:** `GET`
*   **Parameters:**
    *   `q`: The search query.
    *   `category`: (Optional) The category to filter by.
    *   `price_min`: (Optional) The minimum price.
    *   `price_max`: (Optional) The maximum price.
